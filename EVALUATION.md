# Key Phrase Extraction Evaluation

This document explains how key phrase extraction is evaluated in this project.

## Evaluation Process

The evaluation compares extracted key phrases against reference key phrases using precision, recall, and F1 score metrics. The evaluation workflow is:

1. **Reference Data Preparation:**
   - Reference keyphrases are extracted from the book's index (via `split_reference.py`)
   - Organized by chapter with one file per chapter (e.g., `chapter_1_reference.txt`)
   - Both original and stemmed versions are maintained

2. **Extracted Keyphrases:**
   - Generated by different extraction methods (KeyBERT and Ollama)
   - Saved in similar chapter-based structure (e.g., `chapter_1_keyphrases.txt`)
   - Stemmed versions also created for fair comparison with stemmed references

3. **Metrics Calculation:**
   - **Precision:** Percentage of extracted phrases that match reference phrases
   - **Recall:** Percentage of reference phrases found in the extraction
   - **F1 Score:** Harmonic mean of precision and recall
   - Results reported per chapter and as an overall average

4. **Model Comparison:**
   - 4 variants evaluated:
     - KeyBERT (raw phrases)
     - Ollama (raw phrases)
     - DeepSeek (raw phrases) In-Progress
     - KeyBERT (stemmed phrases)
     - Ollama (stemmed phrases)
     - DeepSeek (stemmed phrases) In-Progress

## Running Evaluation

```bash
# Run evaluation on existing results
python scripts/evaluation/evaluate_keyphrases.py

# Generate reference files from index (if needed)
python scripts/evaluation/split_reference.py
```

## Implementation Details

- Text normalization: All phrases are converted to lowercase
- Exact matching is used (no partial credit for similar phrases)
- Stemming uses NLTK's Porter stemmer for fair comparisons
- Empty sets are handled gracefully in F1 calculations
